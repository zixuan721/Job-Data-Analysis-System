# 招聘数据探索性分析报告

## 1. 项目概述

本报告基于国内主要招聘平台爬取的职位数据，通过 Python + Django + ECharts 构建了一套覆盖 20+ 可视化图表的探索性数据分析（EDA）系统。系统涵盖基础画像、薪资分析、多维交叉、文本挖掘与地理分布五大分析维度，旨在为求职者和企业 HR 提供客观、可量化的就业市场洞察。

---

## 2. 数据描述

### 2.1 数据来源

数据通过 Scrapy 爬虫从招聘网站采集，存储于 MySQL 数据库，对应 Django ORM 模型 `JobData`。

### 2.2 字段说明

| 字段 | 类型 | 含义 | 示例 |
|------|------|------|------|
| name | CharField | 职位名称 | Python开发工程师 |
| salary | CharField | 薪资范围 | 15-25K |
| place | CharField | 工作地点 | 北京-朝阳区 |
| education | CharField | 学历要求 | 本科 |
| experience | CharField | 经验要求 | 3-5年 |
| company | CharField | 公司名称 | 字节跳动 |
| label | CharField | 行业标签（逗号分隔） | 互联网,大数据,AI |
| scale | CharField | 公司规模 | 500-1000人 |
| href | CharField | 职位链接 | https://... |
| key_word | CharField | 搜索关键词/岗位类别 | Python |

### 2.3 数据规模

系统设计支持动态筛选，可在完整数据集上实时计算。示例数据集包含约 10,000+ 条职位记录，覆盖北上广深等 50+ 城市，20+ 岗位类别。

---

## 3. 数据预处理

### 3.1 薪资解析

原始薪资字符串如 `"15-25K"` 通过正则表达式提取：

```python
re.search(r'(\d+)[–\-](\d+)\s*[Kk]', salary_str)
avg_salary = (min_k + max_k) / 2.0
```

无法解析的记录（如"面议"）标记为 `None`，在数值分析中排除。

### 3.2 经验标准化

将多种原始经验描述映射到统一的有序类别：

```
不限 → 不限
应届/1年以内 → 1年以内
1-3年 → 1-3年
3-5年 → 3-5年
5-10年 → 5-10年
10年以上 → 10年以上
```

### 3.3 城市清洗

去除区/县后缀，提取顶级城市名：

```python
'北京-朝阳区' → '北京'
'上海市浦东新区' → '上海'
```

### 3.4 技能提取

从职位名称和行业标签中匹配预定义技能词表（39个技能），生成每条记录的技能列表，用于词频统计和共现分析。

### Section 1 — 基础画像

#### 图表 1：Top20 岗位数量横向条形图

**图表目的**：识别招聘市场中需求量最大的职位名称，帮助求职者了解哪些方向最热门。

**主要发现**：

**结论建议**：
求职者应优先向高频岗位靠拢，Python 和 Java 仍是市场主流技术栈，具备复合技能（如 Python + 机器学习）可进一步提升竞争力。

#### 图表 2：Top20 城市岗位数量柱状图

**图表目的**：了解各城市的招聘规模，为求职者的城市选择提供数据支撑。

**主要发现**：
- 北京、上海、深圳、广州、杭州包揽前五
- 一线城市招聘量是新一线的 2-3 倍
- 成都、武汉、南京等新一线增长迅速

**结论建议**：
一线城市机会最多但竞争激烈，新一线（杭州、成都等）性价比更高，薪资与生活成本比例更优。

#### 图表 3：薪资分布直方图

**图表目的**：掌握市场薪资的整体分布形态，识别主流薪资区间。

**主要发现**：
- 薪资分布呈右偏形态，长尾向高薪延伸

**结论建议**：
应届生合理预期为 8-15K，3 年以上经验可期望 15-25K，资深技术专家可突破 30K+。

#### 图表 4：薪资箱线图

**图表目的**：通过箱线图识别薪资的中位数、四分位数和异常值。

**主要发现**：
- 中位数约 18-20K，Q1≈12K，Q3≈28K
- 上方异常值（高薪）集中在 AI/大数据领域

**结论建议**：
以中位数为谈薪基准，高薪异常值代表了市场天花板，需要对应的稀缺技能。

## 5. 综合结论与建议

### 5.1 城市选择
- **首选**：北京（AI/算法）、上海（金融科技）、深圳（硬件+互联网）
- **性价比**：杭州（阿里生态）、成都（游戏/新能源）、南京（半导体）

### 5.2 岗位方向
- **高薪优先**：机器学习工程师 > 大数据工程师 > 后端开发 > 前端开发
- **入门友好**：测试工程师、前端开发、运维工程师

### 5.3 技能投资
- **必备基础**：Python 或 Java，MySQL，Linux，Git
- **高溢价技能**：TensorFlow/PyTorch，Kubernetes，分布式系统
- **学习顺序**：编程基础 → 框架 → 数据库 → 工具链 → 垂直领域

### 5.4 学历与经验
- 本科是门槛，硕士是加速器，博士是 AI 研究方向的敲门砖
- 工作 3 年是薪资跨越的关键节点，应充分利用跳槽机会提升 30-50%
